# Cosmos Palette Reference

## Hex palette

- `#000000` - Void Black
- `#051427` - Deep Space Blue
- `#530f1e` - Nebula Maroon
- `#a44322` - Burnt Copper
- `#f8bc04` - Solar Gold

## Suggested normalized RGB

- `#000000` -> `vec3(0.000, 0.000, 0.000)`
- `#051427` -> `vec3(0.020, 0.078, 0.153)`
- `#530f1e` -> `vec3(0.325, 0.059, 0.118)`
- `#a44322` -> `vec3(0.643, 0.263, 0.133)`
- `#f8bc04` -> `vec3(0.973, 0.737, 0.016)`

## Suggested role mapping

- Base/background: `#000000`, `#051427`
- Secondary accents: `#530f1e`, `#a44322`
- Primary highlights / CTA / key VFX: `#f8bc04`
